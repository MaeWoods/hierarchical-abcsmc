# hierarchical-abcsmc

A module built on top of abcsysbio (http://www.theosysbio.bio.ic.ac.uk/resources/abc-sysbio/). To perform approximate Bayesian computation sequential Monte-Carlo on a hierarchical model within the abcsysbio framework.

This module was applied on a stochastic system describing the repair of double strand breaks, published in the paper: Mechanistic Modelling and Bayesian Inference Elucidates the Variable Dynamics of Double-Strand Break Repair (https://doi.org/10.1371/journal.pcbi.1005131)
